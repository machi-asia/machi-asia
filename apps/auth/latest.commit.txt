- security: user info verified locally against asymmetric JWKS instead of network validation; service-role secret confined to admin/logout paths
- health: add unauthenticated /api/health endpoint used by CI smoke tests
- tests: add 18 Jest tests covering login/token/admin flows, validation errors, and JWKS verification round-trips with real ES256 keypairs
- ci: consume org reusable pr-pipeline-service.yml (lint/typecheck/Jest shards/build/Vercel preview/healthcheck/rollback)
